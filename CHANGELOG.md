# Changelog

All notable changes to **NextRun** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.8.0] — 2026-06-19

### Added

- Motion animations across the marketing surface — fade-in transitions for the navbar and pricing components for a more polished first impression.

## [0.7.0] — 2026-06-05

### Changed

- Reworked the metadata structure for cleaner, more maintainable per-page SEO.
- Updated dependencies across the stack.

## [0.6.0] — 2026-03-11

### Changed

- Broad, audit-driven improvements informed by a full code and SEO review — tightening accessibility, performance, and search visibility throughout.

### Fixed

- Authentication fixes shaking out edge cases from the Better Auth migration.

## [0.5.0] — 2026-03-03

### Added

- A grammY-powered **Telegram bot** to extend NextRun beyond the web app.

## [0.4.0] — 2026-02-26

### Changed

- Migrated authentication to **Better Auth** (Google OAuth, Drizzle adapter) for a more robust, modern auth layer.
- Updated dependencies.

## [0.3.0] — 2026-01-11

### Changed

- Updated all packages to their latest versions.

## [0.2.0] — 2025-09-14

### Added

- SEO metadata foundations — per-page titles, descriptions, and social/Open Graph tags.

## [0.1.0] — 2025-09-12

### Added

- Initial project setup — the NextRun starter built on Next.js, React, TypeScript, Tailwind CSS, Drizzle ORM on Neon Postgres, Stripe payments with a credit system, and shadcn/ui.
